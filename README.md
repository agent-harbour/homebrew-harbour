# homebrew-harbour

Homebrew tap for Harbour.

Harbour source code and product documentation live in:

- https://github.com/agent-harbour/harbour

## Install

```sh
brew tap agent-harbour/harbour
brew install agent-harbour/harbour/harbour
```

The formula installs `colima` as a dependency.

## Maintenance

- Update `Formula/harbour.rb` when Harbour releases change
- Keep the formula version, download URLs, and SHA256 values aligned with the Harbour release
